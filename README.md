# Herminio Gonzalez Marquez S.L.

Web comercial estática en GitHub Pages (`herminiogonzalezmarquez.es`).

## Lo que la web ya cubre

- Aviso legal, privacidad y cookies.
- HTTPS (GitHub Pages, renovación automática del certificado).
- Títulos, descripciones, canonical, `robots.txt`, sitemap y datos estructurados.
- Favicon / iconos, vista previa al compartir (`og-image.jpg`, foto 8).
- Texto alternativo en fotos, página 404, botón de WhatsApp, formulario con campo trampa antispam.
- Teléfono y correo clicables. Una sola acción principal: solicitar presupuesto.

## Lo que hay que hacer una vez en cuentas externas

1. **Google Search Console:** añadir `https://herminiogonzalezmarquez.es`, verificar por archivo HTML o DNS, y enviar `https://herminiogonzalezmarquez.es/sitemap.xml`.
2. **Bing Webmaster Tools:** importar la propiedad o verificar y enviar el mismo sitemap.
3. **Ficha de Google (Business Profile):** completar la ficha de la empresa en Salamanca; no se puede crear desde el código.
4. **DNS:** una sola versión del dominio. En el registrador, `herminiogonzalezmarquez.es` y `www` deben apuntar a GitHub Pages; GitHub redirige www si está configurado en Settings → Pages.
5. **Copias:** el historial de Git es la copia de la web. El correo de Gmail no es copia de la operativa.
6. **Medir conversiones:** WhatsApp y llamadas se ven en el teléfono. No hay Google Analytics (evitar cookies de terceros). Si más adelante se usa Ads, hay que pegar aquí el ID de conversión.

## Publicación

El sitio se publica desde `main` en GitHub Pages, raíz del repositorio.
